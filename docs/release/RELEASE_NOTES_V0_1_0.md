# v0.1.0 candidate — ShashBesh AI Lab

Status: **candidate, unpublished**. These notes describe current preparation,
not an existing GitHub release or deployed Lab service.

- Independent RU/EN web project with nine sections, themes and responsive board.
- Local Core-backed Rules Lab for 2–4 players, chosen demo dice/positions,
  first-attempt Exam and bounded Learning with feedback and audit.
- Agent Pull V1 adapter, isolated Researcher/Agent projections and example client.
- Real local workerd compatibility verified for pinned unchanged Core: 2/3/4
  players, legal actions, rejection/application, modes, replay/native hashes.
- Separate public static build with interactive Rules Lab explicitly disabled.
- Release allowlist, privacy/license review, publication plan and pause handoff.

Not included: public interactive backend, user registration, real billing,
untrusted code hosting, persistent attempt recovery, public rankings, reviewed
complete bilingual benchmark corpus or accelerated long Core Replay.

Local attempts are memory-only. Core workerd CPU/RSS fixtures do not prove
production/cloud-plan budgets. Original Core and research databases remain
unchanged. Public Game remains a separate project and was not modified.

Publication is held pending wider Lab licensing/provenance, reviewed fresh
export, and explicit authorization. No Lab URL/release is marked published.
