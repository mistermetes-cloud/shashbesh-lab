## Реализовано

Девять RU/EN разделов, темы и адаптивность. Локальная лаборатория правил для
2–4 игроков: позиции и кубики Core, предложения действий, Exam/Learning,
история попыток и разделённые Researcher/Agent API. Локальные тесты настоящего
workerd прошли с совпадением хешей Node. Это не развёрнутый публичный backend.

Публичная статическая сборка явно **отключает** интерактивную проверку.
Регистрация, рейтинги, постоянное хранение, публичный API и платежи запланированы.
Чужой исполняемый код не загружается и не запускается.

## Запуск

Нужны Node >=20 и Python >=3.10. Frontend не требует npm-зависимостей.

```sh
cd apps/shashbesh-lab-web
npm run build
python3 server.py --port 8787
```

Откройте `http://127.0.0.1:8787/`, введите временный тестовый код из локальной
консоли. Не публикуйте этот код. Для backend нужен отдельно полученный одобренный
Core artifact с точным SHA256; он не включён в будущий публичный экспорт.
Подробнее — [инструкция приложения](apps/shashbesh-lab-web/README.md).

Подготовка статического предпросмотра без deployment:

```sh
cd apps/shashbesh-lab-web
npm run build:public
```

Каталог результата — `dist-public/`, локальная сборка отдельно в `dist/`.
Не публикуйте Python-сервер, SQLite, приватные эксперименты и текущую Git-историю.
