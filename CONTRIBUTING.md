# Contributing / Участие

This is an unpublished v0.1.0 candidate. Do not treat planned repository links
as active support channels. Once the Lab repository is published and Issues
are enabled, open an issue describing the research question, reproducible
fixture, Core version/hash, UI/rules language, player count and expected result.
Use Discussions for research proposals only when enabled. Maintainers will
confirm the project license/contribution terms before accepting outside work.

Run local frontend/Core tests described in the app README. Preserve original
Core rules and hashes. Propose adapter, projection, documentation and test
changes separately. Do not weaken existing tests, add invented rules or mix
Rules/Strategy or RU/EN benchmark cohorts.

Never submit SQLite databases, private prompts, model/provider credentials,
local console test tokens, raw experiment results, generated dist/node_modules
or copied Game assets. Use minimal synthetic fixtures. External models stay on
the developer's machine; the platform accepts data through Agent Pull V1.

RU: до публикации Lab каналы Issues/Discussions не считаются доступными.
Предлагайте воспроизводимые исследования и небольшие изменения; правила Core
не меняются. Условия лицензирования и приёма внешнего вклада ещё нужно утвердить.
Не отправляйте токены, базы, приватные данные и сгенерированные файлы.
